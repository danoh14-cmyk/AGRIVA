# 아그리바 Android 1.0.0

영농일지, 할 일, 거래와 정산, 필지 관리의 오프라인 초기 소스입니다.
Android Studio에서 이 폴더를 열고 JDK 17, Android SDK 35와 Gradle 8.9를 사용해 :app:assembleDebug를 실행합니다.
생성 위치는 app/build/outputs/apk/debug/app-debug.apk입니다.
로고는 선정한 AGRIVA 딥그린 A·밭고랑 시안을 바탕으로 벡터로 다시 그렸습니다.
날씨, 시세, 지원사업은 예시 데이터입니다. 음성, 사진, 기기 간 공유와 알림은 이 소스에 포함되지 않습니다.
